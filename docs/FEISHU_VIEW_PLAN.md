# FEISHU VIEW PLAN

## 今日任务

使用主表过滤/筛选视图，不复制流水数据。分区：待录工单、待备货、待打印 Label、待取货、今日已出库、今日返修、待处理异常。

展示字段：Pickup Code、SH、SKU、Model、Qty、ERP Warehouse、Source Location、Container、SN、Status。

## 异常视图

按严重度、异常代码、日期、SH/Pickup、负责人筛选。优先卡片：缺 SKU、缺 SN、重复当前 SN、库存不足、库位异常、属性异常、日期格式异常、公式异常。

## 库存视图

- 库存按机型：Model / Condition / Available Qty。
- 库存按库位：Location / SKU / Model / Container / Current Qty / Frozen Qty / Available Qty。
- 库存按属性：新机、维修良品、待修、报废、物料。
- 本周发货、本周返修、本月发货。

## 仓库布局可视化修复

保留现有 R1/R2 与服务区网格，不另建 BI 平台。

目标单元格格式：

```text
R2-4-5-L
97-229-00020-00 × 3
97-223-00088-00 × 4
容器: MIX-008
总数: 7
```

单一料号也必须显示 SKU；混装必须列出每个 SKU，而不是只显示“混装 N 个料号”。空位显示“空”。

实施上先修 `当前库存明细查询` 的现场图文本辅助结果，再让布局页引用。避免在 136 个布局格内各写复杂数组逻辑。小范围验证 3 类样本：空位、单 SKU、混装；回读通过后再批量复制公式。

## 运营看板

顶部指标：今日新工单、待备货、待打印 Label、待取货、今日已出库、今日返修、异常数量。库存指标：新机、维修良品、待修、维修库存、报废。

旧隐藏“数据看板”公式有固定截止行，需新建/改造前先对账，不能直接继续使用其现值。

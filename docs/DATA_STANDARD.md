# DATA STANDARD

## 总则

新记录写入前必须显式转换类型、去除非业务性首尾空白并验证受控值。历史记录只检测和报告，不在未确认来源语义前自动清洗。

## 日期

- A `日期`、B `实际出库日`、周起始日、报告日、创建日、完成日必须存为真实日期值。
- 显示格式统一为 `yyyy-mm-dd`。
- 禁止把 `"2026-08-20"` 作为文本写入日期字段。
- 文本日期标记：`DATE_STORED_AS_TEXT`。
- 备货记录 B 列必须留空；实际出库后才写 B。

## 文本与隐藏字符

- 新 ID 写入前 trim 首尾空格并移除 CR/LF/TAB、零宽字符和 BOM。
- 历史值含首尾空白、换行、制表符或不可见字符时标记 `HIDDEN_CHARACTER`，不静默修改。
- 内部有意义的空格、大小写和标点保留。

## 标识符

| 字段 | 标准 |
|---|---|
| SH_No | 文本；保留业务编号；新值 trim；不得含 CR/LF；按现有惯例大写 |
| Pickup_Code | 文本；正则 `^SYD-[0-9]{5}$`；全局唯一 |
| SN | 文本；首尾无空白；大小写原样；序列化库存当前状态唯一 |
| SKU | 文本；保留前导零；禁止数值化 |
| Container_Code | 文本；若用于备货，必须与实际库存键完全一致 |
| Location_Code | 文本；必须存在于 `库位维护` |

## 数量

- K `数量` 必须为数值。
- 序列化成品每个 SN 行通常 Qty=1。
- 物料 Qty 可大于 1。
- 库存动作 Qty 不得为空。
- 负数、文本数值、序列化小数或 Qty≠1 均报异常；是否允许业务负数需显式规则，当前不允许直接输入负 Qty。

## 动作

只允许：期初库存、备货、出库、退回维修、入库、移库、库存调增、库存调减。禁止自由文本。

## 库存属性

只允许：新机、维修良品、待修、报废、物料。禁止自由文本。

## 必填关系

- 备货：日期、动作、SH、Pickup Code、SKU、Qty、来源库位、ERP 仓库、库存属性。
- 出库：备货字段 + 实际出库日；序列化成品必须有 SN。
- 退回维修：日期、动作、SN、Qty=1、目标库位、待修；SKU/SH 不明时允许暂缺但必须标记待补。
- 移库：SN 或库存键、来源库位、目标库位、Qty、原库存属性。
- 入库/调增：目标库位必填。
- 调减：来源库位必填。

## 写后类型验证

回读后必须验证：日期为 date、Qty 为 number、SKU/SN/SH/Pickup/Location/Container 为 text，Action/Stock Condition 在受控列表内。

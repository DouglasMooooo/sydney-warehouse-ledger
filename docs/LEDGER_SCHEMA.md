# LEDGER SCHEMA

主表：`主表 库存流水`。AI/脚本仅可写业务输入列；公式/辅助列受保护。

| 列 | 名称 | 含义/来源 | 类型 | AI/脚本写入 | 保护 |
|---|---|---|---|---|---|
| A | 日期 | 记录/工单日期 | 真日期 | 确认后可写 | 否 |
| B | 实际出库日 | 实际离库日期 | 真日期 | 出库确认后可写 | 否 |
| C | 动作 | 8 项受控动作 | 文本/下拉 | 确认后可写 | 否 |
| D | ERP SH单号 | 工单或退回关联号 | 文本 | 可写 | 否 |
| E | 取货码 | `SYD-00000` | 文本 | 生成器写 | 否 |
| F | 容器码 | 实际库存容器 | 文本 | 可写 | 否 |
| G | 料号 | Product Master SKU | 文本 | 可写 | 否 |
| H | 机型 | 由 G 查产品维护 | 公式 | 禁止 | 是 |
| I | 物品类型 | 由 G 查产品维护 | 公式 | 禁止 | 是 |
| J | 机器唯一码（SN） | 序列化机器 ID | 文本 | 可写 | 否 |
| K | 数量 | 交易数量 | 数值 | 可写 | 否 |
| L | 来源库位 | 出库/备货/移库来源 | 文本/下拉 | 可写 | 否 |
| M | 目标库位 | 入库/退修/移库目标 | 文本/下拉 | 可写 | 否 |
| N | ERP仓库选择 | 工单 Stock of warehouse 原值 | 文本 | 可写，不得推断 | 否 |
| O | 检查 | 必填与动作校验 | 公式 | 禁止 | 是 |
| P | 库存属性（必填） | 5 项受控属性 | 文本/下拉 | 可写 | 否 |
| Q | 公式辅助位 | 有效库位 | 公式 | 禁止 | 是 |
| R | 公式辅助位 | 退回维修 SN 辅助键 | 公式 | 禁止 | 是 |
| S | 公式辅助位 | 净数量/交易符号 | 公式 | 禁止 | 是 |
| T | 公式辅助位 | 库存键 | 公式 | 禁止 | 是 |
| U | 公式辅助位 | 辅助标记 | 固定辅助文本 | 禁止 | 是 |
| V | 备注 | 来源证据、差异和说明 | 文本 | 可写 | 否 |
| W | 属性校验 | 库存属性业务校验 | 公式 | 禁止 | 是 |
| X | 单据去重标记 | 每动作/SH 首条标记 | 公式 | 禁止 | 是 |
| Y | 旧机未返标记 | 出库 SH 未见退回 | 公式 | 禁止 | 是 |
| Z | 报表整机标记 | Product Master 映射 | 公式 | 禁止 | 是 |
| AA | 报表类别 | Product Master 报表分组 | 公式 | 禁止 | 是 |
| AB | 移库来源键 | 移库来源库存键 | 公式 | 禁止 | 是 |
| AC | 移库来源数量 | 移库来源负数量 | 公式 | 禁止 | 是 |

## 数据源关系

- H/I/Z/AA ← `产品库存维护`。
- L/M 数据验证 ← `库位维护`。
- C 数据验证 ← `动作列表维护`。
- P 数据验证 ← 新机、维修良品、待修、报废、物料。
- `当前库存明细查询` ← Q/R/S/T/AB/AC 及业务字段。
- 周报/月报/布局/看板 ← 主表与当前库存查询。

## 写入边界

新增记录只能写 A:G、J:N、P、V。写入前先确认目标行 H/I/O/Q:U/W:AC 的公式、格式和验证已存在；如缺失，只从相邻同类行复制公式/格式/验证，不复制业务值。

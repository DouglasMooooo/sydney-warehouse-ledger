# DAILY WORKFLOW

## 员工入口

正常员工从“今日任务”开始，不直接操作公式列。

## 工单与备货

1. 上传 ERP 工单或粘贴结构化内容。
2. 只解析 `Replacement Unit information`。
3. 显示 SH、SKU、Qty、ERP Warehouse 和来源证据。
4. 校验 Product Master 与当前库存。
5. 确定性推荐可用库位/容器。
6. 确定性生成 Pickup Code。
7. 预览备货记录；用户确认。
8. 写入后回读，验证公式、检查列、属性、库存和唯一性。
9. 从已确认备货行生成标签数据。

## 实际出库

从待取货记录进入；确认 SN、来源库位、容器和实际出库日期，将动作更新/写为出库。备货本身不扣库存，B 列在实际出库前保持空白。

## 退回维修

粘贴/扫描一个或多个 SN → 查历史 → 展示已知 SKU/Model/SH 与冲突 → 预览 `退回维修 / Qty 1 / REPAIR-01 / 待修` → 批量确认 → 写入并验证。未知 SKU/SH 不猜，标记待补。

## 移库

输入 SN 与目标库位 → 系统查当前来源、容器、SKU、属性 → 验证目标库位 → 预览 From/To → 确认 → 写入移库记录。正常移库不得改变库存属性。

## 调整

“维修完成”按 SN 查询后建议 `库存调增 / FLEX-01 / 维修良品`；目标可改为其他有效库位。任何调增/调减都必须预览确认。

## 每日收尾

检查待处理异常、未打印标签、待取货、今日出库与今日返修；异常未清零时明确负责人和原因，不静默修历史数据。
